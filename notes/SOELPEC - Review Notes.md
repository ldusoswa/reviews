## Key Specifications

### Physical Design
- **Diameter**: 297mm
- **Weight**: 1,350g (without rear hub)
- **Structure**: 6061 Anodized Aluminum
- **Grips**: 50A Overmold Silicone
- **Button Caps**: PMMA with LED Diffusers
- **Style**: Closed-bottom handles for rigidity and comfort

### Input Configuration (136 Total Inputs)
- **Push Buttons**: 13x with 700gf tactile switches
- **7-way Switches**: 2x
- **Center Rotary Encoders**: 4x Custom HybridSwitch with push buttons
- **Thumb Encoders**: 2x Dual-Action Custom Illuminated (up to 24 inputs with HybridSwitch Mode)
- **Telemetry LEDs**: 10 additional configurable
- **Rear-Facing Buttons**: Tactile buttons for vital car functions
- **Dedicated Settings Button**: Quick access to wheel functions

### Illumination
- **RGB LEDs**: 128 individual LEDs, fully customizable
- **LightSync Technology**: Encoder input illumination with dynamic position feedback
- **Encoder LEDs**: 12 individual LEDs per center encoder
- **Compatibility**: SimHub integration for telemetry-synced animations

### Shifters & Clutches
- **DuoAct Mechanism**: Industry-first dual actuation system
  - High-durability tactile switch (1M+ cycle rating)
  - Secondary analog Hall-effect input with configurable activation point
  - Ball bearing shifters with both tactile & Hall sensors
- **Clutches**: Spring mechanism for linear analog control, programmable for multi-step inputs
- **Adjustability**: Magnetic force adjustment with included extra magnets
- **Magnets**: Black N52 magnets with ball bearings
- **Adjustment System**: Precisely defined positions (no sliding slots) for angle and distance

### Customization Features
- **Modular Rotary Knobs**: Swappable colors and styles
- **Stickers**: Textured PVC film stickers for buttons and encoders (extra sheet included)
- **HybridSwitch Encoders**: 
  - Function as 12-position switch or multi-input encoder
  - Up to 6 control layers per encoder
  - Configurable pulse count (12, 6, 4, 3, or 2-position modes)
- **HybridLink**: Thumb encoders mappable to 12 different encoder sets
- **SOELPEC Overlay**: Signature control interface for management

### Connectivity
- **Rear Hub**: 32mm color-coordinated with integrated USB connection
- **Mounting**: 70mm 6-hole pattern (compatible with most DD wheelbases)
- **USB PassThrough**: Type-C port for cleaner cable management
- **Cables**: 4-pin spiral cable with Lumberg connector, internal USB for QR connection

### LED & Power Issues Encountered
- **LED Failure**: One encoder cluster (bottom right) completely failed during testing
- **Cause**: Likely loose cable inside unit (per SOELPEC)
- **Resolution**: Replacement sent without questions, return label provided
- **Customer Service**: "Top quality" - fast, no hassle
- **Uniqueness**: Only unit with this issue reported (reviewer tends to find failures)
- **Brightness Limitation**: Had to run at ~50% brightness
  - At 80%+ experienced wheel crashes
  - Isolated to SimMagic QR/wheelbase power limitation (not wheel fault)
  - 50% still "plenty powerful" and not a dealbreaker
  - Recommendation: Use powered USB hub for higher brightness

### Software & SimHub Integration

#### Setup
- **No Proprietary Software Required**: Uses SimHub (most users already have)
- **Basic Setup**: Add device in SimHub devices screen
- **Advanced Setup**: SOELPEC plugin for SimHub ("where the smarts really are")
- **Lighting Profiles**: All included free (saves subscription costs vs third-party)

#### Clutch Paddle Features ("Insanely versatile")
- **Multi-Function Mapping**: Can map to throttle/brake or other functions
- **Increment/Decrement**: Use as brake bias adjusters (e.g., +5/-5 clicks)
- **Practical Example**: Adjust bias for Bus Stop at Spa, then revert
- **Two Rapid Presses**: Dynamic high/low modes
- **Dead Zones**: Fully configurable
- **Calibration**: Press and hold dedicated button, pull paddles, done ("super simple")
- **Auto-Switch Mode**: Clutches at race start, become buttons at speed
  - Speed or race state triggered
  - "Sci-fi stuff" - designed by racers

#### Shifter Features ("Most advanced ever reviewed")
- **Dual Detection**: Simple switch + dynamic calibrated mode
- **Fail-Safe Mode**: Auto-switches between detection methods if one fails
  - Critical for endurance events or high-use scenarios
- **Double Shift Protection**: Prevents accidental double upshifts
  - Won't register second shift until full release
  - More important for upshifts (no car protection like downshifts)
  - Can save "a second a lap" at circuits like Spa
- **Analog Mode**: Shifters can function as analog paddles ("insane")
- **Calibration**: Same simple process as clutches

#### Advanced Functions
- **Throttle Hold**: Hold throttle on straights to stretch/address cramps
- **Brake Magic Mode**: Hold specific brake percentage (e.g., 5% for pace laps)
  - Consistent application without pedal input
  - Linked to rear wheel buttons
- **Mouse Emulation**: Press and hold button, encoders control mouse
  - Paddle shifters become left/right click
  - White LED indication when active
  - Cool animation on enable/disable
  - Can control in-game menus without keyboard/mouse

#### Encoder Customization
- **Modes Available**:
  - Default encoder (simple up/down)
  - Track encoder (12 individual tracked segments)
  - Hybrid, Hybrid Link, Thumb Encoder modes
- **Input Count Display**: Visual representation of mode (no need to understand technical terms)
- **Tracked Mode**: White segments light up to show position
- **Knob Animation**: Shows correct knob type in software when changed

#### HybridLink Naming
- **Function Mapping**: Assign real function names to inputs
- **Auto-Linking**: Software links to telemetry animations automatically
- **Example**: Input 3 = "Traction Control" → shows TC animation when adjusted
- **Dashboard Integration**: Works with on-screen overlays

#### LightSync Illumination Styles
- **Single Segment**: Only current position lights
- **Progressive**: All segments up to current position
- **Clean/Simple**: Minimal lighting distraction
- **White Only**: Simple white indication
- **Segments Only**: Just active segments (good for engine modes, ABS levels)

#### RGB Customization
- **Settings Mode Access**: Dedicated settings button
- **Color Scheme**: Left/right encoder to change overall scheme
- **Combination**: Up/down for color scheme variations
- **Brightness**: Adjustable via encoder
- **Rev Lights**: Multiple styles available
  - Preferred: Linear blue to red
  - Preview shown in settings mode
- **Flag Effects**: Yellow, blue, etc. with animations
- **Traction Control/ABS**: Visual feedback during use
- **Spotter Effects**: Integrated
- **Push Button Animation**: Temporary color change on press (can disable)
- **Offline LED**: Shows when no telemetry active
- **Breathing Idle**: Breathing effect when idle (can disable, reviewer not a fan)
- **7-Way Hat Animations**: "Lovely little animations" when moved

#### Bite Point Adjustment
- **Top Right Encoder**: 1% increments
- **Right Encoder**: 10% increments
- **Quick Adjustment**: Can jump directly to desired percentage (e.g., 45% to 65%)
- **Visual Feedback**: Clear indication in settings mode
